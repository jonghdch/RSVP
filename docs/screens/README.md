## 공통 정책

| 영역 | 정책 |
|---|---|
| 알림(토스트) | 쓰지 않는다. 상태는 화면 안의 글과 버튼 모양으로 알린다 |
| 내 행동 확인 | 재생 버튼 문구(재생/일시정지)와 진행 막대가 바뀌는 것으로 확인한다 |
| 위험한 행동 | 지우는 기능이 없다. 글을 고치면 읽던 위치가 처음으로 돌아간다. 확인 창은 띄우지 않는다 |
| 저장 | 저장하지 않는다. 글은 브라우저 밖으로 나가지 않고 새로고침하면 사라진다 |
| 불러오기 | 서버 통신이 없으므로 로딩 상태가 없다 |
| 오류 문구 | 네트워크 오류가 생길 일이 없다. 입력 문제(빈 글)는 안내 문구로 알린다 |
| 눌림 영역 | 모바일 44px, 데스크톱 24px 이상 |
| 움직임 | 단어 전환에 애니메이션을 넣지 않는다. 움직임 줄이기 설정을 켠 경우에도 단어 표시는 그대로 하고 장식 전환만 끈다 |
